**创新点草案**（可直接进技术文档）：

**技术创新点**
1. **检索的「按文档配额」机制**：多文档对比时按论文配额抽取片段，解决「语义最贴近的文档垄断上下文」导致对比失败的问题；
2. **PageRank 限定在库内子图计算**：外部文献作为悬挂节点会使全图 PageRank 退化为均匀分布（实测 178 节点全部 0.006252），限定子图后恢复区分度；
3. **BM25 结果的信息量过滤**：以 IDF 相对区分度判定关键词检索是否可信，不可信时跳过该路，避免噪声排名挤掉向量检索的正确结果；
4. **去重的四层递进判定**：内容指纹 → arXiv 编号与版本 → 文件名规范化 → 语义近似，能区分「同篇不同文件名」与「同篇不同版本」；
5. **抗幻觉的第三层（服务端引用校验）**：不只依赖提示词，回答落地前校验编号合法性并清除越界引用。

**应用创新点**
1. **界面上的数字全部可回溯到数据库**：主动移除无法追溯的统计列，拒绝「看起来完整」的假数据；
2. **失败原因分级展示**：「没有检索到片段」与「检索到但模型未引用」分别呈现，让使用者能判断问题出在检索还是模型；
3. **元信息类问题的固定片段机制**：首页块（标题/作者/机构）必进上下文，把「作者是谁」这类高频问题从「靠检索碰运气」变成确定性回答；
4. **翻译的按块缓存与嵌入保留**：重复翻译 0.01 秒返回；重新解析时保留未变块的向量，避免重复付费。

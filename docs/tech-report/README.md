# 技术文档写作说明

本目录是**技术文档 PDF（≤30 页）**的源文件。内容用 Markdown 写，`build.py` 负责转成 PDF。

## 怎么构建

```powershell
cd "D:\Desktop\科研小助手-web"
.\backend\.venv\Scripts\python.exe docs\tech-report\build.py
```

输出：

- `技术文档.pdf` —— 交给赛方的成品（封面 + 目录 + 正文 + 页码）
- `技术文档.html` —— 调试排版用，可直接用浏览器打开看效果

加 `--html` 只生成 HTML（快，不调用 Edge）。

**构建脚本会在超过 30 页时告警**，这是官方硬上限。

## 文件约定

| 文件 | 内容 |
|---|---|
| `ch01-项目概述.md` … `ch08-总结与展望.md` | 正文章节，**按文件名排序**拼接 |
| `appA-接口清单.md`、`appB-踩坑精选.md` | 附录 |
| `img/` | 截图与示意图，Markdown 里写 `![图 1-1 首页](img/home.png)` |
| `build.py` | 构建脚本（Markdown 子集 → HTML → Edge 无头打印 → PDF） |

## 支持的 Markdown 语法（只这些，够用）

- 标题：`#`（章）、`##`（节）、`###`（小节）。**每章第一行必须是 `# 第 N 章 标题`**
- 段落、有序列表 `1.`、无序列表 `-`
- 表格：标准 `| a | b |` + `|---|---|`
- 代码块：三个反引号，可标语言（` ```python `）
- 图片：单独一行 `![图 1-1 说明](img/xxx.png)`
- 引用块：`>`
- 行内：`**粗体**`、`` `代码` ``、`[链接](url)`

## 排版规则（由 CSS 统一控制，不要在正文里写样式）

- A4，页边距 20mm/17mm，正文 10.5pt，行高 1.75
- 每章强制另起一页
- 表头浅蓝底、1px 细边框；表格不跨页断行
- 代码块浅灰底 + 左侧蓝条
- 页码写在页脚，**封面不显示**

## 页数预算（总计 ≤30）

| 第 8 章 总结与展望 | 1.5 |
| 附录 A 接口清单 / 附录 B 踩坑精选 | 2 |
